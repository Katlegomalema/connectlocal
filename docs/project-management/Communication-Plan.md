# Communication Plan — ConnectLocal

## 1. Introduction
Defines how the project team, academic supervisor, and other stakeholders communicate throughout the ConnectLocal project.

## 2. Purpose
To ensure timely, consistent information flow that supports coordinated delivery and academic oversight.

## 3. Scope
Covers internal team communication, supervisor reporting, and documentation update practices.

## 4. Detailed Content

### 4.1 Communication Matrix
| Communication | Frequency | Medium | Audience | Owner |
|---|---|---|---|---|
| Daily stand-up | Daily (async or 15-min sync) | Team chat (Slack/Discord/Teams) | Project team | Project Lead |
| Sprint Planning | Start of each sprint (bi-weekly) | Video call + GitHub Projects board | Project team | Project Lead |
| Sprint Review / Demo | End of each sprint | Video call | Project team + Academic Supervisor (as available) | Project Lead |
| Sprint Retrospective | End of each sprint | Video call | Project team | Project Lead |
| Supervisor Check-in | Fortnightly | Meeting + written progress summary | Academic Supervisor | Project Lead |
| Milestone Review | Per milestone (see Project Charter) | Formal presentation/report | Academic Supervisor, External Assessor | Project Lead |
| Issue/PR Discussion | As needed | GitHub Issues / Pull Requests | Project team | Assignee |
| Documentation Updates | Continuous, PR-based | GitHub (this repository) | Project team, reviewers | Task owner |

### 4.2 Escalation Path
Blocking issues are raised immediately in the team channel; if unresolved within 24 hours, escalated to the Project Lead, who determines whether supervisor input is required.

### 4.3 Meeting Notes
All meeting notes are recorded using the template in `docs/meeting-notes/Meeting-Notes-Template.md` and committed to `docs/meeting-notes/` for auditability.

## 5. Assumptions
- All team members have reliable access to the chosen chat/video tools throughout the semester.

## 6. Constraints
- Meeting scheduling must accommodate team members' other coursework timetables; fixed weekly slots are agreed at project kickoff.

## 7. Future Enhancements
- Introduction of a shared project dashboard (e.g., GitHub Projects insights) for automated status reporting to the supervisor.
