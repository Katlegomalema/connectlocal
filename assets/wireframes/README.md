# Wireframes

This directory holds low-fidelity wireframes for ConnectLocal's core screens, produced during the System Design phase to validate user flows before high-fidelity mockup and implementation work begins.

## Planned Contents
- `customer/` — search, provider profile, booking flow, messaging, reviews
- `provider/` — onboarding, service management, booking requests, availability
- `admin/` — dashboard, verification queue, dispute management

## Tooling
Wireframes are produced in Figma; exported PNG/PDF snapshots are stored here for version-controlled reference alongside the code and documentation.
