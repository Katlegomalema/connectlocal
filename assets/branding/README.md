# Branding Assets

This directory holds ConnectLocal's brand assets: logo files (SVG/PNG at multiple resolutions), color palette definitions, and typography guidelines.

## Planned Contents
- `logo/` — primary logo, icon-only mark, wordmark, in light/dark variants
- `colors.md` — brand color palette with hex/RGB values and usage guidance
- `typography.md` — font families and type scale used across the Flutter app

## Brand Direction (summary)
ConnectLocal's visual identity emphasizes trust and locality: a warm, approachable color palette paired with clear, legible typography suited to a wide age range of local service customers and providers.
