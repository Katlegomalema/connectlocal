# High-Fidelity Mockups

This directory holds high-fidelity, styled mockups of ConnectLocal's core screens, reflecting the finalized branding and UI component design.

## Planned Contents
- `customer/` — polished screens for search, booking, payment, reviews
- `provider/` — polished screens for onboarding, service and availability management
- `admin/` — polished dashboard screens

## Tooling
Mockups are produced in Figma using the component library defined alongside `assets/branding/`, and exported here for reference during Flutter implementation.
